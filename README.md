# Offline Field Issue Tracker

A full-stack offline-first application for field workers to report infrastructure issues in environments with unreliable connectivity.

## Project Status

Initial project setup.

## Planned Architecture

- Frontend: React + Vite
- Backend: FastAPI
- Server database: SQLite
- Local offline storage: IndexedDB
- API: REST
- Testing: Pytest + Vitest

## Core Features

- Create and manage infrastructure issue reports
- Offline report persistence
- Automatic synchronization when connectivity returns
- Synchronization status and retry handling
- Report status workflow
- Report history
- Coordinator review
- Automated tests
